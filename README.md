# Developer Portfolio

A static HTML, CSS, and JavaScript portfolio. No build step or package installation is required.

## Publish with GitHub Pages

1. Create a public GitHub repository named `PORTFOLIO-1012` and push this project to its `main` branch.
2. In the repository, open **Settings → Pages** and set the build and deployment source to **GitHub Actions**.
3. The workflow at `.github/workflows/pages.yml` deploys the site after a push to `main` or `master`. You can also run it from the repository's **Actions** tab.
4. Wait for the deployment to finish. The Pages address appears in the workflow deployment summary and in **Settings → Pages**.

For the repository `PORTFOLIO-1012`, the expected public URL is:

`https://YOUR-GITHUB-USERNAME.github.io/PORTFOLIO-1012/`

For a special repository named `YOUR-GITHUB-USERNAME.github.io`, the public URL is:

`https://YOUR-GITHUB-USERNAME.github.io/`

The site uses relative asset paths, so it works both at the repository URL and at the account root. Certificate details and the developer's name remain placeholders until real information is added.
